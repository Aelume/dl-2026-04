# dl-2026-04

## 题目名称

数据获取与处理：多源数据获取、处理及常见的数据增强方法

## 这是一道什么题

这道题主要考查：

- 数据集获取能力
- 文件结构整理
- 检测标注清洗与异常样本处理
- 图像尺寸标准化与标注同步变换
- 数据增强与增强后标注校验
- train / val / test 划分
- 数据质量报告与分层统计能力

本题不是让你追求最高模型精度，而是看你能不能把钢铁缺陷检测数据整理成一个真正能用于 YOLO / 检测模型训练的数据集。所有保留图像必须至少包含 1 个有效标注。

## 数据集选择

请选择下面二者之一：

- GC10-DET 钢材表面缺陷检测数据集
- Severstal Steel Defect Detection 数据集，常被称为俄罗斯谢维尔钢铁缺陷数据集

必须在报告中写清楚：

- 下载来源
- 原始标注格式
- 类别定义
- 原始图像数量
- 原始有标注图像数量
- 原始无标注图像数量

## 你的任务

### 1. 获取数据并解析原始标注，15 分

要求：

- 下载或获取原始数据
- 保留原始数据目录 `data/raw/`
- 编写或整理标注解析脚本
- GC10 需要解析检测框标注；Severstal 需要从 RLE 或原始标注中得到缺陷区域，并转成检测框输出 `raw_annotation_summary.csv`

评分：

- 数据来源真实可访问，4 分
- 原始数据保留清楚，3 分
- 原始标注解析正确，4 分
- 类别与数量说明正确，4 分

### 2. 数据清洗、有效标注过滤与正方形化，30 分

请将数据整理为类似结构：

```text
data/processed/
├── images/
│   ├── train/
│   ├── val/
│   └── test/
├── labels/
│   ├── train/
│   ├── val/
│   └── test/
└── meta/
```

至少完成：

- 删除打不开的图片
- 删除重复图片或近似重复图片
- 删除没有任何有效标注的图片
- 删除标注框宽度或高度小于阈值的图片或标注，阈值需要自己设定并解释
- 删除越界、面积为 0、类别未知的标注
- 将所有图像改换为正方形，例如 padding 到正方形或裁剪后重算标注
- 正方形化后必须同步更新标注坐标
- 统一输出为 YOLO txt 或 COCO json，二选一，但必须说明选择理由
- 按固定随机种子划分 train / val / test

评分：

- 目录结构标准，4 分
- 能检测并删除损坏图片，4 分
- 能处理重复或近似重复图片，3 分
- 保证每张保留图像至少 1 个有效标注，5 分
- 过小标注过滤阈值合理，3 分
- 正方形化与标注同步变换正确，5 分
- 划分比例与随机种子清楚，3 分
- 清洗脚本可重复运行，3 分

### 3. 数据增强与增强后标注校验，20 分

要求：

- 至少实现 4 类增强，如水平翻转、亮度/对比度扰动、随机缩放、随机裁剪、Mosaic、轻微旋转
- 所有几何增强必须同步更新标注
- 增强后仍需保证每张图像至少 1 个有效标注
- 增强后不得产生越界框、负面积框、空标签文件
- 保存增强前后对比图到 `figures/augmentation_examples/`

评分：

- 增强方法数量与实现达标，5 分
- 几何增强标注同步正确，5 分
- 增强后有效标注校验完整，4 分
- 增强前后样例图清楚，3 分
- 能解释哪些增强适合钢铁缺陷，哪些可能破坏语义，3 分

### 4. 压轴：分散粒度表与数据效果展示，20 分

请提交 `dataset_report.md`，必须包含“分散粒度表”，从多个粒度展示清洗与增强效果。

至少包含以下表格：

- 按 split 统计：train / val / test 的图像数、标注数、平均每图标注数
- 按类别统计：每类图像数、标注数、占比
- 按缺陷尺寸统计：small / medium / large 标注数量，阈值自定并解释
- 按清洗阶段统计：raw、去损坏、去重复、去无标注、去过小标注、正方形化、增强后的数据量变化
- 按图像粒度统计：每图 1 个缺陷、2-3 个缺陷、4 个及以上缺陷的数量

同时提供：

- 每类至少 5 张带框可视化样本
- 清洗前后对比图
- 正方形化前后对比图
- 增强后标注可视化图

评分：

- 分散粒度表完整，5 分；能使用 Origin 画出对应图且图示清晰者，本项最高 8 分
- 数据量变化解释清楚，4 分
- 带框可视化样本充分，4 分
- 能从表格中指出数据问题，3 分
- 图表排版清晰，1 分

### 5. 压轴：数据泄漏、脏标签与标注质量审计，15 分

请额外完成一次数据质量审计，并写入 `audit_report.md`。

至少完成以下 4 类检查：

- 检查同一张或高度相似图片是否同时出现在 train 和 test
- 检查类别标签是否疑似错误或混淆
- 检查标注框是否明显偏移、过大、过小或漏标
- 检查是否存在文件名、背景、图像尺寸等“捷径特征”

要求报告中必须包含：

- 审计方法
- 发现的问题
- 证据截图或样本路径
- 你会如何修复
- 修复前后数据量变化

评分：

- 审计方法描述清楚，3 分
- 证据具体，不是泛泛而谈，4 分
- 修复策略合理，3 分
- 能说明数据清洗移对 mAP 的影响，3 分
- 能提交审计脚本或可复查表格，2 分
